Temos a honra de receber Pavel Yosifovich, especialista de renome mundial em Windows Internals, autor prolífico e instrutor de elite com expertise inigualável em programação de sistemas.

Atualmente atuando como Co-Founder na TrainSec Academy e Chief R&D Officer na CYMDALL, Pavel é especialista em desenvolvimento de software na plataforma Windows, utilizando intensivamente C++, .NET, Rust e APIs de kernel.

Além de sua passagem como Principal Software Engineer na Microsoft, Pavel é coautor do lendário livro "Windows Internals (7ª edição)" e autor de "Windows Kernel Programming", além de ter criado cursos de altíssimo nível para plataformas como Pluralsight e Pentester Academy.

Na sua palestra "Hidden Windows: The Undocumented Native API", ele compartilhará insights técnicos profundos, trazendo uma visão detalhada da API "pública" Win32 versus a API Nativa não documentada (NtDll.dll), demonstrando como autores de malware utilizam técnicas como Direct Syscalls para burlar soluções modernas de EDR e antivírus.
